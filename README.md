# Fitness Tracker Dashboard

A simple multi-page fitness tracker built with HTML5, CSS3, and basic JavaScript.

## Pages

1. **Dashboard** (`index.html`) - stats and charts
2. **Workouts** (`workouts.html`) - log form and activity list
3. **Health Goals** (`health.html`) - metrics, goals list, add/edit modal

## Run locally

Open `index.html` in your browser. No build step required.
